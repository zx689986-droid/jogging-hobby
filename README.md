# 조깅 소개 웹페이지 / 慢跑介绍网页
## 📌 작품 목적 / 作品用途
조깅에 대한 정보를 소개하는 간단한 소개 웹사이트입니다.
这是一个介绍慢跑相关知识的简单介绍网站。

## ✨ 주요 기능 / 主要功能
- 한중 양문 텍스트 표시 / 中韩双语文字展示
- 조깅의 장점과 시작 방법 안내 / 慢跑优点与入门指南

   在浏览器打开 index.html 文件即可查看。
